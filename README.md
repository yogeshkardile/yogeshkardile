## 🚀 Featured Projects

### 1. YReport — ML Data Diagnostics Library

An open-source Python package designed to evaluate dataset quality and ML readiness.

**Key Features:**
- Weighted Data Health Score (0–100)
- Automatic column type detection
- Missing value diagnostics
- High-cardinality detection
- Skewness and outlier analysis
- JSON and Markdown report generation
- Published on PyPI

🔗 [GitHub Repository](https://github.com/yogeshkardile/yreport)

### 2. Fashion Visual Similarity Search

A deep learning-powered visual search engine for fashion images.

**Key Features:**
- ResNet50 feature extraction
- Triplet Network architecture
- Triplet Loss and Batch-Hard Mining
- Reduced embedding dimensionality from 2048D to 128D
- FAISS-based similarity search
- Search across approximately 47K fashion images

**Tech Stack:** Python, PyTorch, ResNet50, FAISS, Streamlit.

### 3. Locora — Multi-Agent AI Research Assistant(Currently  Working)

An AI-powered research assistant for automated literature review and research gap detection.

**Key Features:**
- PDF ingestion using PyMuPDF
- Document chunking and embedding generation
- Vector-based semantic retrieval
- Research summarization
- Research paper comparison
- Research gap identification
- Automated report generation

**Tech Stack:** Python, FastAPI, RAG, ChromaDB, Embeddings, LLMs.

### 4. Olympic Data Analysis

An exploratory data analysis project focused on discovering insights from Olympic datasets.

**Key Features:**
- Data cleaning and preprocessing
- Exploratory data analysis
- Statistical insights
- Interactive dashboards
- Data visualization

**Tech Stack:** Python, Pandas, NumPy, Matplotlib, Seaborn, Streamlit.
